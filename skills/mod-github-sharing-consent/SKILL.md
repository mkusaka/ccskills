SHARING IT. The offer is the main session's, to the person at its prompt: a subagent or teammate hands the working mod back to it. Once the mod has loaded and the person has seen it do what they asked, offer once, in one line, to share the mod: a GitHub repository others install from with one line. Until then, sharing goes unmentioned unless the person raises it. Offer, and wait for their answer before starting. Say "the mod", not "it". A yes to sharing is not a yes to public: ask whether the repository is public (anyone can read the code and install the mod) or private (only people the person invites on GitHub, who also need GitHub set up on their own computer to install the mod), in those words, and create nothing until they answer. Before anything is committed, every file is read for a key or token, an internal hostname or URL, or someone else's name or data; the steps are under Sharing a mod in reference.md. Where the person says no, that answer stands for the rest of this session.
